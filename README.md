# Schengen Visa Agent. ДЗ №1 «Агент с инструментами»

### Выполнили: Мамонтова Дарья, Зарянкина Варвара, Ермолина Елизавета, Малашко Виктория

Агент помогает гражданам РФ подготовиться к подаче на туристическую визу во Францию, Италию или Испанию. В одном запросе можно получить ссылку на официальный портал, посмотреть учебную статистику по срокам и найти похожие примеры подачи.

> Для ДЗ используем синтетическую базу из 36 кейсов. Сроки, доли одобрений и индекс сложности рассчитаны на этих данных. Перечни документов даны для ориентира. Актуальные требования нужно проверять на официальном портале.

## Быстрый старт

Нужен Python 3.10 или новее. Команды выполняются из корня репозитория.

```bash
git clone https://github.com/dmamontova/schengen-visa-agent.git
cd schengen-visa-agent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
test -f .env || cp .env.example .env
```

Новый `.env` включает `mock` - офлайн-режим с детерминированным выбором инструментов. Он подходит для первого запуска и автоматических тестов, API-ключ не нужен. Для прогона с моделью см. [настройку GigaChat](#gigachat).

## Примеры запуска

Ниже - два прогона исправленной версии с `GigaChat-2` и `gigachat==0.2.4`. Те же команды работают в `mock`. Порядок вызовов и число шагов модели в живом запуске могут отличаться.

### Документы, сроки и кейсы по Франции

```bash
python -m schengen_agent.cli --question \
  "Франция Москва: какие документы нужны, сколько ждать рассмотрения и есть ли похожие учебные кейсы?" \
  --trace
```

В этом прогоне модель сначала запросила документы и кейсы. Перед завершением агент заметил, что для вопроса о сроках не был вызван `get_visa_statistics`, и дал модели ещё один ход. Третий инструмент появился в трассе, общий счётчик показал пять шагов модели.

| Вызов в `TRACE` | Результат |
| --- | --- |
| `get_visa_requirements` | Ориентировочный список и ссылка на France-Visas |
| `search_visa_cases` | 8 совпадений, показаны 3 учебных кейса |
| `get_visa_statistics` | 8 кейсов и 8 известных решений за 90 дней |

Из ответа агента:

```text
Медиана ожидания записи: 18,5 дня.
Медиана рассмотрения: 15 дней.
Наблюдаемая доля одобрений: недостаточно данных (нужно минимум 10 известных решений).
```

Окно статистики отсчитывается от даты запуска, поэтому при повторе на том же наборе кейсов цифры могут измениться. В тестах дата зафиксирована.

### Таймаут поиска кейсов по Италии

```bash
python -m schengen_agent.cli --question \
  "Найди учебные кейсы подачи на визу в Италию по всем городам, сразу выполни поиск" \
  --fault-demo --trace
```

`--fault-demo` имитирует таймаут при каждой из двух попыток поиска. Модель получила итоговую ошибку и сообщила, что сервис недоступен. Обе попытки отражены в одной записи `TRACE`.

```text
TRACE:
[
  {
    "tool": "search_visa_cases",
    "duration_ms": 0.64,
    "attempts": 2,
    "error_type": "timeout",
    "result_items": null
  }
]
Model steps: 2
```

Если CLI выводит `[DEMO NOT EXERCISED]`, модель не вызвала поиск и сценарий сбоя не был выполнен.

## Инструменты и цикл агента

| Инструмент | Когда вызывается и что возвращает |
| --- | --- |
| `get_visa_requirements` | Вопрос о документах или подаче. Возвращает официальный портал и ориентировочный чек-лист. |
| `get_visa_statistics` | Вопрос о сроках или статистике. Считает размер выборки, медианы, долю одобрений среди известных решений и учебный индекс сложности. Для доли и индекса нужно минимум 10 известных решений. |
| `search_visa_cases` | Запрос на похожие случаи. Фильтрует по стране, при необходимости по городу и предыдущим визам. Возвращает до пяти синтетических примеров. |

Город можно опустить — поиск и статистика охватят все города выбранной страны. Все три инструмента только читают локальные JSON-файлы, поэтому подтверждение действий не требуется. Контракты из восьми полей для каждого инструмента приведены в [спецификации ДЗ](docs/specification.md#контракты-инструментов-восемь-полей).

Модель выбирает инструмент и аргументы. Исполнитель проверяет аргументы через Pydantic, вызывает функцию и передаёт результат или структурированную ошибку обратно модели. По умолчанию цикл ограничен шестью шагами, временный сбой инструмента допускает один повтор, третий одинаковый вызов блокируется. Трасса показывает имя инструмента, время выполнения, число попыток и тип ошибки.

Если в вопросе о сроках указана страна из базы, а модель пытается завершить ответ до вызова статистики, агент может до двух раз предложить ей пропущенный инструмент в пределах лимита шагов. Итоговые цифры подставляет код из результата инструмента. При отсутствии результата агент сообщает, что сводная статистика недоступна.

## Тесты

```bash
python -m pytest -q
```

В исправленной версии 31 автоматический тест. Набор запускается без сети и ключа.

| Сценарий | Ожидаемое поведение |
| --- | --- |
| «Привет!» | Один шаг модели, пустая трасса. |
| `period_days=999` | Ошибка `validation`, инструмент не выполняется. |
| Поиск по Италии без города | Поиск охватывает все города, вымышленные кейсы возвращаются без ссылок на Telegram. |
| Поиск по Испании, Екатеринбург, без предыдущей шенгенской визы | По этим фильтрам нет кейсов, возвращается `no_data`. |
| Менее 10 известных решений | Доля одобрений и индекс равны `null`, в ответе указано, что данных недостаточно. |
| Модель завершает ответ после документов и кейсов | Агент даёт ей дополнительный ход для запроса статистики. Если модель продолжает пропускать инструмент, агент завершает ответ без оценок сроков. |
| Отсутствует файл данных | Ошибка `data_error` после одной попытки. |

## Подключение модели

### GigaChat

```bash
python -m pip install -e '.[dev,gigachat]'
```

Для запуска с `GigaChat-2` укажи эти настройки в локальном `.env`.

```dotenv
AGENT_PROVIDER=gigachat
AGENT_MODEL=GigaChat-2
AGENT_TIMEOUT_SEC=60
GIGACHAT_BASE_URL=https://api.giga.chat/v1
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_CREDENTIALS=put_your_auth_key_here
```

`GIGACHAT_CREDENTIALS` — ключ авторизации GigaChat API. Храни его в локальном `.env`. В `.env.example` оставь только заглушку.

Если Python на macOS не доверяет цепочке TLS, сохрани `Russian Trusted Root CA` в `.certs/` и укажи абсолютный путь в `.env`. Проверка TLS остаётся включённой. [Инструкция Сбера по сертификатам](https://developers.sber.ru/docs/ru/gigachat/certificates)

```dotenv
GIGACHAT_CA_BUNDLE_FILE=/absolute/path/to/.certs/russian_trusted_root_ca_pem.crt
```

```bash
python -m schengen_agent.diagnostics
```

Диагностика последовательно проверяет авторизацию, текстовый запрос и приём схем функций. При `HTTP 422` смотри, проходит ли минимальная функция или ошибка появляется только на схемах проекта. При `ConnectTimeout` сначала проверь подключение к API и серверу авторизации. [Справочник ошибок GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/errors-description)
